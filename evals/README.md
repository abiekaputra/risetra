# Evaluation fixtures

The first fixture records the method-routing expectations and unsafe claims for seven
discipline families. It is intentionally small and auditable. Future model evaluations
must record the model, prompt bundle, module versions, raw output, rubric result, and
reviewer decision rather than reporting an unsupported accuracy percentage.

The initial fixture covers engineering, social science, education, health, law,
humanities, and practice-based research. It tests routing boundaries rather than
pretending that seven examples establish universal accuracy.
