# Agent adapters

Risetra keeps its research method vendor-neutral. Thin adapters tell Codex and Claude
Code where to find the same skill, modules, records, and validation commands.

- `codex/README.md` documents Codex installation and invocation.
- `claude-code/CLAUDE.md` provides the Claude Code workspace adapter.

An adapter may adapt discovery and invocation syntax. It may not weaken academic
integrity, evidence provenance, or human review gates.
