# Quantitative research pack

Use this pack when the question requires measurement, estimation, comparison,
association, prediction, or a causal test supported by an appropriate design.

Define the target population, unit of analysis, sampling frame, inclusion rules,
constructs, operational variables, measurement instruments, sample-size rationale,
missing-data policy, assumptions, analysis plan, uncertainty reporting, and privacy
controls.

Do not infer causation from association. Do not choose a test solely because it is
familiar. Name the estimand or decision each analysis supports and specify assumption
checks before seeing the result.

The student must explain what a plausible result would and would not allow them to
claim.
