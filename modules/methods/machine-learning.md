# Machine-learning research pack

Define the prediction or representation task, decision context, dataset provenance,
unit of analysis, target construction, split strategy, leakage controls, baseline,
metrics, subgroup analysis, uncertainty, reproducibility, model-card limits, and human
oversight.

Do not select a model only because it is complex. Keep preprocessing inside the
evaluation boundary and compare against a meaningful baseline. Performance on one split
does not establish deployment usefulness.

The student must explain how a prediction would be used, who could be harmed by error,
and what evidence is still required before real-world use.
